# 3–4 minute walkthrough script

0:00–0:25 — Explain the problem in one sentence. Paste a real JD, company URL and days. Start generation. Show the concrete stages; disclose any time cut.

0:25–1:05 — Open Research & sources. Show actual discovered pages, source gaps and the coverage check. Show a genuine repair trace. If using the automated omission test, explicitly identify it as a controlled test, not a live model result.

1:05–2:00 — Edit one question, pin another, add a manual question and reorder. Regenerate that category and show the protected questions surviving. Explain revision-based compare-and-swap and the stale-write conflict behavior.

2:00–2:40 — Reveal a flashcard, record low confidence, finish/restart the session, and show weak-first ordering. Show the study schedule and exact requested number of days.

2:40–3:15 — Open readiness. Trace a requirement back to its JD excerpt and forward to its questions and confidence. Explain why coverage is not the same as confidence.

3:15–3:45 — Show a successful batch command, tests and one limitation. Explain why scheduling/coverage are deterministic and why the deployment uses a single durable worker for this timebox.

Keep claims specific. Discuss the code in your own words. Do not imply a successful model call or public deployment if only the fictional example is running.
